# Versioning — ask-permissions

This repository follows the ask-rb versioning policy: pre-1.0 breaking API or behavior changes use a one-step minor bump, compatible fixes use a one-step patch bump, and all numeric increments advance by exactly one. The changelog keeps an `Unreleased` section.

All releases go through `gemchain` from the ask-rb workspace. Releases require a clean tree and passing tests; do not publish this gem manually.
